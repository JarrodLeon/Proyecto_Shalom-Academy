Sobre este proyecto web

Información técnica sobre cómo está construido el sitio de Shalom Academy.

Propósito

Este sitio fue desarrollado como proyecto académico, con el objetivo de presentar a Shalom Academy: su historia, programas, galería, medios de contacto, ubicación y contenido multimedia, siguiendo buenas prácticas de diseño web responsivo.

Tecnologías utilizadas
  • HTML5 semántico
  • CSS3 con hoja de estilos externa (css/style.css)
  • Bootstrap 5 (framework responsivo)
  • JavaScript nativo (Geolocation API, formularios, galería)
  • Google Maps Embed API
Enfoque de diseño

El sitio se construyó bajo la modalidad Mobile First: los estilos base están pensados para pantallas pequeñas, y se amplían progresivamente mediante media queries para tablets y escritorio.

Estructura del sitio

7 páginas conectadas mediante un menú de navegación global y enlaces de "anterior / siguiente" en cada página, permitiendo recorrer el sitio de ida y de vuelta.

Créditos

Como base de referencia visual e inspiración de estilo para este proyecto se utilizó la plantilla gratuita Mochi Space, de Tooplate.
